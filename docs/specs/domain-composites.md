# Domain Composites

Status: Approved/Frozen. Components are reusable UI workflows; business data remains consumer-owned unless state is explicitly local. Source prop and data-object shapes are evidence only; replacement APIs may differ while preserving data meaning and workflow outcomes.

## AI, Analysis And Comparison

- `SOURCE-COMP-001`: `AiResultPanel` requires `isPending`, `hasError`, `onRetry`, `hasResult`; optional score/scoreLabel/summary/sections/actions/idle/children. Section is `{icon:'success'|'danger'|'primary'|'info',title,items:string[]}`. Pending suppresses other content; error appears only when no result and not pending; result appears only when hasResult and not pending; only nonempty section item arrays render; idle appears only when no pending/result/error and supplied. Actions display whenever not pending, including idle/error states.
- `SOURCE-COMP-002`: `AtsAnalysisPanel` requires controlled value/onValueChange/onSubmit/onReset; optional result `{overallScore,categories:{label,score}[],recommendations:{label,message,severity:'critical'|'warning'|'suggestion'}[]}`, loading/errorMessage/inputLabel/inputHint. Loading takes precedence; error with no result shows alert and reset; result shows score/category progress/recommendations and reset action; otherwise editor/analyze. Score thresholds >=86 success, >=71 primary, >=51 warning, else error. Recommendation severity maps critical->danger, warning->warning, suggestion->info. Submit receives no payload; consumer reads current controlled value. `AGENT-DEC-005` adds local duplicate-submit protection and a safe, retryable inline error on rejection while retaining entered text.
- `SOURCE-COMP-003`: Comparison dialog behavior is in data-display. Preserve structured axes/datasets/columns/rows and async pending/result states. `AGENT-DEC-005` guards duplicate compare requests; rejection preserves visible dialog state and reports a retryable non-sensitive error.

## Editing, Markdown And Code

- `SOURCE-COMP-010`: `MarkdownRenderer` requires content string; renders Markdown with `remark-gfm` plugin through `solid-markdown`. `MarkdownEditDialog` requires open/label/initialValue/onSave/onClose. Draft resets to initialValue when opened. Preview is deferred by 150ms; save emits current draft then closes; cancel resets draft and closes. Its close/Escape path is cancel.
- `SOURCE-COMP-011`: `CodeBlock` requires code string; optional language/maxHeight. Splits on newline, renders one-based line numbers, language placeholder when omitted, and copy action; maxHeight becomes CSS custom property. Copying uses clipboard feedback contract.
- `USER-COMP-012`: `USER-DEC-002` is authoritative: Markdown with GFM does not render raw HTML; rich-text output is constrained and sanitized with `isomorphic-dompurify`. Source uses an HTML string, but target value/callback names and representation may differ if formatting capability and safe rendered result remain equivalent. `AGENT-DEC-021` defines the tag/URI allowlist.

## Collection And Workflow Components

- `SOURCE-COMP-020`: `EditableCollection<T>` requires readonly items, `getId(item)`, `renderItem(item,{requestRemove})`, onAdd and onRemove(id); optional confirmVariant primary/danger and addButtonVariant. Each remove request opens a confirmation for the item's ID; confirmation calls onRemove then clears pending ID. No async pending/error state is provided.
- `SOURCE-COMP-021`: `KanbanBoard<T extends {id,columnId,title,description?}>` requires columns `{id,label}[]`, items and onChange; optional renderCard(item). Unknown item column IDs are retained as extra rendered groups. HTML drag/drop moves item to target column, preserving array order and all other item properties; same column is ignored. It does not reorder within a column. Keyboard reordering is not provided by source and requires accessible alternative in rebuild.
- `SOURCE-COMP-022`: `TransferList` behavior is in composite-widgets.
- `SOURCE-COMP-023`: `ColorLabelManagerDialog` requires open/label/items/colors/onClose/onCreate/onUpdate/onDelete. Item shape `{id,name,color}`. Default color is first provided color or `#3b82f6`; creation uses `crypto.randomUUID()`. Name is trimmed and nonempty before save. Edit keeps id/other properties, updates trimmed name/color. Async create/update/delete set pending and clear it in finally. Delete is confirmed. `ColorLabelSelectionDialog` requires open/label/items/value/cancelLabel/onClose/onSubmit; optional description/chipsLabel. It snapshots value on each opening, blocks cancel/close while submitting, awaits submit then calls onClose. Source rejection propagates and shows no local error; `AGENT-DEC-005` supersedes it: on rejection keep dialog/form open, clear pending, show localized non-sensitive alert and allow retry; no consumer data commit or close.
- `SOURCE-COMP-024`: `ImportSourcesDialog` requires open/title/sources/submitLabel/onClose/onSubmit; optional errorMessage/busy. Source union: URL `{value,label,kind:'url',inputLabel,inputPlaceholder?,helperText?}` or file `{value,label,kind:'file',accept?,dropLabel,dropHint?,clearLabel}`. Tabs appear for >1 source; per-source drafts are retained while switching. When opened with current source absent, selects first source; closing clears drafts and resets active source to first. Submit disabled with no valid source, while busy, without trimmed URL or without file. Payload is `{source,url}` or `{source,file}`. Busy disables source switching/file clearing/cancel. Parent errorMessage is displayed. `AGENT-DEC-005` adds local in-flight protection; rejection leaves selection/drafts open, displays generic localized error, and permits retry.
- `SOURCE-COMP-025`: `FlashcardPracticeSession<T>` requires items/getId/renderFront/renderBack/onFinish/emptyMessage; optional getBadgeLabel/onQuit/height. Result is `{id,item,known}` preserving original item reference. Session resets when `items` prop identity changes. It shows rate buttons only after flip, records answer and advances; final answer invokes onFinish with full ordered result list. `FlashcardPracticeCard` requires front/back; optional badgeLabel/badgeVariant/flipped/onFlip/height. `FlashcardPracticeSummary` requires results/title/onRestart; optional onBack; known percentage rounds to integer and is 0 for empty results.
- `SOURCE-COMP-026`: `PracticeSetupPanel` takes title, description, categories `{value,label}`, count options, optional initial category/count and `onStart`. Category defaults to `initialCategory ?? 'all'`; count defaults to `initialCount ?? first count option ?? 10`. A synthetic localized “all categories” option maps to `categoryId: null`; other values pass through. Start emits `{categoryId,count}`. Changes to initial props reset local selections.
- `SOURCE-COMP-027`: `TimelineCard` contract is in data-display. Edit-save rejection leaves the edit dialog/draft open and clears saving state; `AGENT-DEC-005` adds a localized inline retryable error. Delete rejection keeps confirmation open and does not close; error is visible and retry is allowed.

## Acceptance

- State matrices cover pending/error/empty/result and sync/async callbacks, success/failure/close/reset ordering, source switching, draft retention, and repeated invocation.
- User-supplied Markdown/HTML, imported URLs/files, labels and IDs are handled at trust boundaries without XSS, unsafe URL navigation, or duplicate-ID state corruption.
- `coverage.md` records source-capability-to-behavior coverage for every composite export before approval; legacy type/signature parity is not required.
