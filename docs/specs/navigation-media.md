# Navigation And Media

Status: Approved/Frozen. Routing integration requires `@solidjs/router` where the current router-backed behavior is needed. Source item/type shapes are evidence only; the replacement API may differ while preserving route matching, navigation outcomes and accessible state.

## Navigation

- `SOURCE-NAV-001`: `NavItem` is `{label,href,icon}`. `Navbar` requires navItems; optional logo/actions/showActiveLabel defaults active label on. Mobile menu toggles from hamburger and closes on Escape/path change. Route links use Solid Router `A`; preserve nav labels/current-page state. `AGENT-DEC-012` replaces exact matching/first-item fallback with most-specific path-segment matching; `/` is exact only, other hrefs match exact path or `href + '/'` descendants; no match means no current item.
- `SOURCE-NAV-002`: `MenuBar` requires items `NavItem[]` and activeIndex number; `MenuItem` renders each icon link with tooltip and current-page state; `MenuIndicator` receives numeric activeIndex. `SidebarItem` is `{id,label,icon?,badge?,children?}`. `Sidebar` requires items; optional activeId/onSelect/collapsed/collapsible/onToggle/header; collapsed false, collapsible true. Search is local, case-insensitive label match, recursively retains ancestors with matching descendants; only-badged toggle retains matching descendants; any nonempty query force-expands branches; clear resets both filters. Collapsed hides tools and nested child rows; toggle button only appears when collapsible and onToggle exists.
- `SOURCE-NAV-003`: `SidebarNav` requires groups `{label,items:{id,label}[]}` and label; optional activeId/onSelect/subtitle/actions. `SidebarItemButton` requires label; optional prefix/suffix/badge/hasChildren/expanded/active/collapsed/onClick/style. Expanded version is affix button, collapsed version icon-only button with label.
- `SOURCE-NAV-004`: `BottomNavItem` is `{id,label,icon,badge?}`; `BottomNav` requires items/activeId/onChange, placement defaults viewport, alternative container. `AGENT-DEC-018` gives nav a localized accessible name and exposes active item as current without changing callback. `BreadcrumbItem` is `{label,href?,onClick?}`; `Breadcrumbs` requires items; separator may be JSX or zero-arg factory; maxItems defaults Infinity. Current final item is text with current-page semantics; non-current href uses anchor, onClick uses button, otherwise text. Collapsed form is first + ellipsis + trailing items; ellipsis expands all. `AGENT-DEC-017` displays all items when maxItems <2.
- `SOURCE-NAV-005`: `Pagination` extends supported HTMLElement native props; requires controlled page/totalPages/onChange. Displayed page clamps to 1..totalPages; shows up to seven page items around current plus endpoints/ellipses, previous/next. Page buttons expose `aria-current=page`. For `totalPages<=0`, source renders no page items and disables previous/next; no page callback can be reached. Ellipsis placeholder side is encoded by `left-ellipsis/right-ellipsis` but visually renders `...`.
- `SOURCE-NAV-006`: `Stepper` requires steps `{value,label}[]` and activeStep string; earlier steps completed, equal active, later pending; unknown active value makes all pending. `BackToTop` extends base Props; optional threshold defaults 300, smooth defaults true, optional `scrollRoot(): HTMLElement|null|undefined`; tracks passive scroll with frame-throttled update and scrolls selected root/window to top. `SpeedDial` requires actions `{icon,label,onClick}[]`; optional icon, position bottom-right by default or bottom-left/top-right/top-left/inline, direction up by default/down/left/right. Empty actions disables trigger. Action runs then menu closes.
- `SOURCE-NAV-007`: Preserve router/path contracts, current-page semantics, all documented navigation outcomes, and action ordering. Responsive CSS layout and input object shapes may be redesigned without changing item outcomes.

## Media

- `SOURCE-MEDIA-001`: `Avatar` extends div-native props excluding children; optional src/alt/name/size/variant/status. Size md default, variant circle unless rounded; status online/offline/busy/away. Image error switches the instance to fallback; fallback is up to two initials from name or user icon. Non-image fallback has img role/name from alt, name, or localized avatar label. Source does not reset the error when src changes; `AGENT-DEC-023` proposes retrying a changed source.
- `SOURCE-MEDIA-002`: `AvatarGroup` requires children; max default 5 and size md. Keeps first max children, shows `+N` overflow, reverses visible child order for visual stacking. Nonpositive max behavior follows `AGENT-DEC-027`.
- `SOURCE-MEDIA-003`: `ImageGridItem` is `{src,alt?,caption?}`. `ImageGrid` requires images; columns default 3, gap spacing-sm, rounded/hoverable true, optional onImageClick(index). Images lazy-load; missing alt defaults decorative empty alt. Clickable cell button accessible name precedence caption > alt > generated “Open image N”.
- `SOURCE-MEDIA-004`: `Carousel` extends div-native props excluding children; requires children; optional autoplay false and interval 5000ms. Slides are direct children; prev/next wrap; dots navigate; active index syncs from scroll position; auto-play pauses only on pointer hover in source and uses interval timer. Empty carousel controls still render; zero-width and one-slide handling follows `AGENT-DEC-027`.
- `SOURCE-MEDIA-005`: `Marquee` extends div-native props and requires children; speed default 30 seconds, direction left, pauseOnHover true, gap spacing-xl. Duplicated track is aria-hidden. `AGENT-DEC-022` requires reduced-motion handling; proposed pause-on-focus behavior is in `AGENT-DEC-027`. `MediaNavButton` requires direction prev/next and label, forwards supported button props.
- `SOURCE-MEDIA-006`: `Lightbox` behavior is in overlays-feedback. `Icon` accessible naming is in primitives/forms.

## Acceptance

- Route navigation uses router-native links where required, active page is programmatically exposed, responsive menu is operable by keyboard, and nested sidebar navigation preserves selection/filter behavior.
- Image alternatives distinguish decorative from meaningful content. Carousel and marquee respect reduced-motion preference and do not create duplicate spoken content.
- Every public navigation/media capability and unresolved edge behavior is recorded in this spec or `coverage.md` before approval; source object shapes are not target requirements.
