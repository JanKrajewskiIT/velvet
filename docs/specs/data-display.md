# Data Display

Status: Approved/Frozen. Source data shapes are evidence and may be redesigned. Preserve semantic data, callback/action timing, ordering and empty/loading/error outcomes.

## Lists, Trees And Timelines

- `SOURCE-DATA-001`: `List` requires children and accepts default/bordered variant. `ListItem` requires label, optional icon/secondary/action, and supported list-item native props except onClick. Without onClick it renders static content; with onClick it renders a button inside the list item.
- `SOURCE-DATA-002`: `VirtualizedList<T>` extends div-native props excluding children; requires items, itemHeight, height and `renderItem(item,index)`, optional overscan default 4 and emptyState. Visible count is `ceil(height/itemHeight)+2*overscan`; start is `max(0,floor(scrollTop/itemHeight)-overscan)`, end is clamped to item count. Scroll updates are frame-scheduled. Empty state defaults to localized no-items. It exposes list/listitem roles, total-height spacer and translated inner offset. Invalid dimensions and stable item identity follow `AGENT-DEC-023`.
- `SOURCE-DATA-003`: `TreeView` node shape is `{id,label,icon?,hasChildren?,children?}`. Selection/check/async loading/keyboard/drag behavior is specified in [composite-widgets.md](composite-widgets.md); preserve controlled/default expansion and checked IDs, selected ID, loaders and move/select callbacks.
- `SOURCE-DATA-004`: `Timeline` takes ordered `{key,dotClass?,content}` items and optional trailing JSX. `StatusTimeline` requires items `{key,statusTone?,content}` and emptyMessage, optional action; tones are default/success/danger/muted. It uses EmptyState with localized no-items hint/action when empty.
- `SOURCE-DATA-005`: `TimelineCardData` is `{id,category,status,dateTime:string|null,duration,location,notes,isSynced?}`. `TimelineCardLabels` requires `category,status,dateTime,duration,location,notes,editDialogLabel,deleteDialogLabel,deleteDialogMessage,syncedLabel`. Options are `{value,label,icon?:IconTypes|JSX.Element,chipVariant?}`. Props require value, labels, categoryOptions/statusOptions, async `onSave(value)`/`onDelete()`, optional calendarAction and date/time/duration formatters. Date defaults to locale day/month/year, time to locale hour/minute, duration appends ` min`. Empty datetime shows localized not-set. Category/status use matching option labels, notes render Markdown, sync shows a badge. Edit save sets pending, awaits onSave, closes on success and clears pending in finally; delete is confirmed. Rejections follow `AGENT-DEC-005`.
- `SOURCE-DATA-006`: `TimelineCardEditDialog` is controlled by open/value with optional loading, labels, category/status options, onClose/onSave. On open it snapshots source fields into a draft; dateTime converts between ISO and local `datetime-local`, empty becomes null on save. Nested Markdown dialog edits notes. Save emits full value retaining untouched fields.

## Tables And Filtering

- `SOURCE-DATA-010`: `Table`, `TableHead`, `TableBody`, `TableHeader`, `TableRow`, and `TableCell` preserve native table semantics and their scoped native attributes. `Table` wraps the table in a surface/card container, accepts separate table class and containerClass.
- `SOURCE-DATA-011`: `DataTableColumn<T>` requires `key: keyof T & string` and header; optional sortable/filterable, render(value,row), width, sortAccessor/sortFn, filterAccessor/filterFn. `DataTableProps<T extends Record<string,unknown>>` requires data/columns; optional pageSize default 10, sortable default false, striped/hoverable, filterable, controlled filterQuery/onFilterQueryChange and global filterFn. Column sortable overrides table default; false always disables. Column filterable false excludes it. Global filterFn overrides column filtering. Sort cycles asc/desc on same column, starts asc on a new column; sort/filter resets page to 1. Query is controlled when supplied, otherwise internal. Pagination is 1-based and shown only above one page. Empty rows render localized no-data cell; filter toolbar shows result count. `AGENT-DEC-016` requires declared striped/hoverable options to work.
- `SOURCE-DATA-012`: Page changes outside valid bounds are ignored. Total pages is at least one even when no rows. Default cells render `String(value ?? '')`; custom renderer receives row field value and complete row. Width is passed through a CSS custom property. Filtering/sorting details are in [foundation.md](foundation.md); preserve copy-on-filter/sort semantics. `AGENT-DEC-016` requires invalid pageSize to fall back to 10.

## Charts And Metrics

- `SOURCE-DATA-020`: `RadarChart` requires axes `{label,key}[]` and datasets `{label,values,color?}[]`; size defaults to 300. Values clamp 0..100; missing positions are zero. Five fallback colors cycle primary/info/success/warning/error; chart has four grid levels. Axis key is descriptive only; values align by array position. Replacement must provide an accessible textual/table summary, not only visual color/geometry.
- `SOURCE-DATA-021`: `ScoreRing` meter/threshold contract is in [overlays-feedback.md](overlays-feedback.md). `ComparisonSelectionBar` requires selectedCount/onCompare, optional compareDisabled/onClear; clear action appears only with callback and positive count.
- `SOURCE-DATA-022`: Public data shapes are `Axis {label,key}`, `Dataset {label,values:number[],color?}`, `Column {label,description?,accentColor?}`, `Row {label,values:string[]}`. `ComparisonInsightsDialog` requires open/title/prompt/onClose/onCompare/hasResult, optional isPending/selectionSummary/axes/datasets/columns/rows. With no result and not pending it displays prompt, optional selection summary and compare action. Pending displays spinner. Result displays chart only when axes and datasets are nonempty and table only when columns are nonempty. Each row renders one value per column; missing values become empty strings. Result state shows a close action invoking onClose; it does not clear external data itself.
- `SOURCE-DATA-023`: Radar/chart handling of mismatched array lengths, non-finite values, duplicate keys, absent axes, and mismatched row/column counts is not a stable source contract. Replacement validation/fallback behavior follows `AGENT-DEC-024`.

## Acceptance

- Ordering, filtering, sort direction, paging, virtualization window, tree state, callback payloads, empty states and event spans are evaluated with consumer inputs.
- Tables remain actual tables; tree/list semantics and keyboard contracts remain navigable; chart values remain inspectable without visual-only encoding.
- Each source data-display export maps to behavior in [coverage.md](coverage.md); the replacement may use new public type/prop names while preserving data meaning and rendered outcomes.
