# Primitives And Forms

Status: Draft. Source component and prop names are evidence labels only. Under `USER-DEC-009`, the replacement API may be redesigned; preserve semantic input/output, validation, focus, form submission and user-visible state transitions.

## Common Component Contract

- `SOURCE-PRIM-001`: Map each source primitive to its user-facing capability. Source names/signatures are not target contracts; preserve meaningful input/output, validation, native form participation, accessibility, and controlled/uncontrolled user-visible behavior.
- `SOURCE-PRIM-002`: Sizes exposed by shared controls are generally `sm | md | lg`; preserve only per-component supported sizes. Disabled controls cannot activate. Read-only controls remain focusable where the native pattern requires it but cannot mutate value.
- `SOURCE-PRIM-003`: Preserve semantic native elements where they define form behavior, names, validation, browser keyboard behavior, or URL navigation. Accessible names and error relationships are consumer-visible contracts.

## Buttons And Typography

- `SOURCE-PRIM-010`: `Button` supports `primary | danger | ghost | dashed | outline | subtle | navbar`, size sm/md/lg default md, loading, icon-only, round, content class, and a discriminated label-or-children API. Default variant is primary and type button. Loading exposes `aria-busy`, shows spinner and visually hides content. Source computes disabled as `Boolean(disabled ?? loading)`; `AGENT-DEC-006` requires loading always disable regardless of explicit false. `IconButton` requires icon and nonempty label, supports size/variant/iconSize/iconVariant, defaults to subtle variant and uses label for title/aria-label. `RoundIconButton` adds popover/glow elevation default popover and round styling. `AffixButton` requires text and accepts optional prefix/suffix and their classes. `CopyButton` requires text, supports ghost/outline and size, uses clipboard API; success/failure localized state lasts 2 seconds and clipboard rejection is visible.
- `SOURCE-PRIM-011`: `ThemeToggle` accepts optional variant light/navbar/dark (default light), requires `ThemeProvider`/i18n contexts, uses resolved light/dark state, and calls `setTheme` with explicit light/dark. It does not expose system choice in its segmented control. `LocaleSwitcherProps` accepts optional ordered locales and ButtonVariant; it renders current locale uppercase, size sm, and cycles to next with wrap. Empty locale list leaves selection unchanged. It requires i18n context.
- `SOURCE-PRIM-012`: Public typography types are `TypographyTone` (`default|muted|secondary|tertiary|inverse|primary|inherit`), `TextVariant` (`bodyLg|bodyMd|bodySm|labelLg|labelMd|caption|overline`), `HeadingVariant` (`displayLg|displayMd|h1|h2|h3|titleLg|titleMd`). `Heading` accepts supported HTMLElement props, optional polymorphic `as`, level 1..6 default 2, variant and tone. Default tag is hN from level; default visual variant maps levels 1/2/3/4 to h1/h2/h3/titleLg and 5/6 to titleMd. Explicit variant overrides visual variant, not semantic tag. `Text` accepts supported HTMLElement and anchor native props, optional `as` default p, variant bodyMd and tone default. `LabelText` accepts optional label/description; label-only uses span, label+description uses wrapper with separately styled text; renders nothing if both absent. `CodeText` accepts supported HTMLElement props, optional `as`, variant inline/block default inline, size sm/md default sm, tone; default tag code for inline/pre for block, default tone secondary for inline/default for block. `Kbd` wraps supported HTMLElement props/children in native kbd.
- `SOURCE-PRIM-013`: `Icon` requires Solid icon component, optional size sm/md/lg default md, variant inherit/muted/primary/info/success/warning/error/inverse default inherit, optional label/aria-label. Explicit label gives role img and aria-label; absent label sets aria-hidden unless caller explicitly supplies aria-hidden. Caller role/aria-label/aria-hidden override defaults where specified.
- `SOURCE-PRIM-014`: Public `TabButton` requires label (`string | JSX.Element`), optional selected and variant underline/pill default underline, plus supported native button props except children. Selected pill uses primary button styling; unselected pill and underline use ghost styling; selected underline adds primary text/underline state.

## Surfaces And Layout

- `SOURCE-PRIM-020`: `Surface` extends div-native props; optional polymorphic `as` defaults div, children, tone default/subtle/inverse/glass (default default), elevation flat/sm/card/popover/dialog/drawer (default sm), radius sm/md/lg (default lg), border (default true), blur/clip (default false), ref. `Card` extends div-native props; optional as/children/padding default/none (default default)/hoverable false/radius/clip. `DataCard` extends div-native props, requires children, optional media/header/footer, variant filled/elevated/outlined default elevated, hoverable false. `FeatureCard` requires icon/label/description; optional tone primary/info/warning/success default primary and animationOrder default 0. `StatCard` requires value/label; optional icon/iconSize and colorClass info/warning/success/error. Private class hooks remain non-contracts.
- `SOURCE-PRIM-021`: `Stack` requires children; direction vertical/horizontal default vertical, gap spacing token, align start/center/end/stretch/baseline default stretch, justify start/center/end/between/around/evenly default start, wrap false. `Grid` requires children; columns default 12, optional minColumnWidth switches to auto-fit minmax, gap and alignItems/justifyItems start/center/end/stretch default stretch. Generated CSS custom properties are combined with caller style; caller keys override generated keys. `MainLayout` accepts optional navbar/footer and children; navbar/footer render only while authenticated or auth loading; children are inside Suspense with PageLoader fallback.
- `SOURCE-PRIM-022`: `Divider` orientation horizontal/vertical default horizontal, optional label and solid/dashed variant default solid. Label only renders for horizontal orientation. `Footer` requires copyrightText/privacyLabel/privacyHref/builtWithText; homeHref defaults `/`; links use Solid Router.
- `SOURCE-PRIM-023`: `ResizablePanel` accepts children, direction horizontal/vertical default horizontal, initialSplit default 50, minSize default 10 percent per side and optional onResize(split percent). Only first two children render. Pointer/mouse drag updates split and callback on animation-frame; global mouse listeners are removed on pointer release/disposal. Current implementation lacks touch and keyboard resize. Add accessible keyboard and pointer/touch parity in rebuild; this is a quality improvement that must preserve split callback values.
- `SOURCE-PRIM-024`: `FlipCard` extends div-native props; requires front/back JSX, optional controlled isFlipped/onFlip, width/height, axis vertical/horizontal, frontClass/backClass. Uncontrolled flip defaults false; click, Enter and Space toggle. `FlashcardPracticeCard` requires front/back; optional badgeLabel, badgeVariant, flipped/onFlip and height default `18.75rem`; it composes FlipCard with 100% width. `FlashcardPracticeSummary` requires results (each exposes known:boolean), title and onRestart; optional onBack. It calculates rounded known percentage (0 for empty results), known/unknown/total counts and restart/back actions.

## Form And Choice Controls

- `SOURCE-FORM-001`: `FormFieldProps` extends supported div-native props except children and ARIA field props. Optional label/id/description/error/required/invalid; children required as JSX or `(controlProps)=>JSX`. Generated field ID is stable per instance unless id provided. It joins caller labelledby/describedby with generated label/description/error IDs; controlProps supplies id/aria-labelledby/aria-describedby/aria-invalid/aria-errormessage. Error renders role alert; required marker is decorative. Group role defaults group, and invalid sets data-invalid.
- `SOURCE-FORM-002`: `FormLayout` requires children, wraps them in vertical Stack gap md. `FormGrid` requires children, uses auto-fit min column width 280px/gap md. `ActionRow` requires children, direction horizontal, align center, gap md; align defaults center, options start/center/end map to justify. These are layout helpers, not validation engines.
- `SOURCE-FORM-003`: `FieldBase`, `Input`, `TextArea`, and `AffixInput` retain native input/textarea attributes allowed by current types; expose size, invalid, read-only and disabled; field focus styling is visible for direct controls and within for compound controls. ARIA invalid derives from explicit `invalid` or passed `aria-invalid`.
- `SOURCE-FORM-004`: `Checkbox` forwards native choice props and optional label/description/id/labelId; controlled checked and native input events. `RadioGroup<T>` requires controlled value, options `{value,label,description?,disabled?}[]`, onChange; optional name/direction row/column. Generates name if absent. `Switch` requires checked/onChange; optional label/description; click emits negated checked; role switch, aria-checked and computed labelledby. `SegmentedControl` requires options `{value,label,ariaLabel?,disabled?}[]`, value and onChange; optional size sm/md, disabled, option/active classes and indicator (default true). Role radiogroup/radio. Right/down and left/up wrap among enabled options, Home/End move to first/last enabled; navigation immediately focuses and selects; clicking selects. Selection is controlled by caller.
- `SOURCE-FORM-005`: `SliderProps` requires controlled numeric value/onChange; optional id/name/min/max/step/marks and ARIA field props. Bounds default 0/100; positive step else 1. Value is snapped from min then clamped. Marks clamp/sort by value. `RangeSliderProps` requires controlled `{min,max}` and onChange; optional bounds/step/marks/id/name/disabled/ARIA field props. Endpoints clamp and reorder; min thumb never exceeds max, max thumb never drops below min. Track pointerdown updates nearest thumb; distance ties use midpoint. Native range controls have localized minimum/maximum labels and submitted names `${name}Min`/`${name}Max`.
- `SOURCE-FORM-006`: `RatingProps` extends div-native props except onChange; requires value; optional onChange/max/size/icon/getValueLabel. Max defaults 5, size md. Without callback renders noninteractive spans; with callback renders radio buttons, selected integer is rounded/clamped, fractional visual fill remains possible. ArrowRight/Up increases, Left/Down decreases; Home/End endpoints; Enter/Space selects; hover previews. Custom value-label function gets 1-based index and max.
- `SOURCE-FORM-007`: `ColorPickerProps` extends ARIA field props; optional id/disabled/class, required colors/value/onChange. Controlled radio group, first color gets tab stop when value absent. ArrowRight/Down and Left/Up move bounded (not wrapping), Home/End select endpoints; each move focuses and commits. Accessible name is color string.
- `SOURCE-FORM-008`: Internal `ChoiceControl` (not a root export) underpins checkbox/radio controls. It wraps a native checkbox/radio input in a label, takes native choice-input attributes plus required type, optional label/description/label ID/custom indicator, and joins caller `aria-labelledby` with generated/provided text ID. The custom indicator is decorative; native input owns checked/disabled/form semantics.
- `SOURCE-FORM-009`: Public `CheckboxIndicator` accepts optional checked and class, renders an aria-hidden visual span. Native checkbox remains the actual interactive control.

## Public Form-Control Inputs

- `SOURCE-FORM-010`: `Input` accepts the declared `InputCoreNativeProps` subset, size sm/md/lg or null (null suppresses size styling), invalid and native ARIA error/name/value/form/validation events. `TextArea` accepts its narrower native textarea subset, size and invalid. `AffixInput` accepts the input subset, size/invalid, optional prefix/suffix elements and separate outer/input classes; it provides a within-focus compound field.
- `SOURCE-FORM-011`: `NumberInput` requires controlled numeric value and `onChange`; optional min/max/step/id/name/disabled/readOnly/required/invalid/size plus ARIA field props. Defaults are unbounded min/max and step 1. Input text is trimmed; blank or NaN emits nothing; valid values clamp. ArrowUp/Down increments/decrements. `AGENT-DEC-007` requires exactly one immediate step per pointer press, repeat after 400ms at 80ms intervals while held, and stop on release/leave/disposal.
- `SOURCE-FORM-012`: `SearchInput` requires controlled value and `onInput(value)`, optional `onClear`, `debounce` milliseconds and size; forwards the remaining input props except value/onInput. Positive debounce delays callback and replaces pending timer. Clear cancels pending timer, emits empty string then calls onClear. Escape clears unless consumer prevented default.
- `SOURCE-FORM-013`: `PasswordInput` forwards input props except `type`, optional size, starts hidden, toggles `type=password/text`, and exposes localized toggle label and `aria-pressed`.
- `SOURCE-FORM-014`: `OtpInput` requires controlled string value and onChange, defaults length 6; optional disabled/size. It truncates overlong values when length changes. Each slot is a text input with numeric input mode, max length 1 and one-time-code autocomplete. `USER-DEC-007` filters entered/pasted content to ASCII digits `0-9`; accepted characters replace slot/current code and focus advances. Backspace on empty slot and left/right arrows move focus. Paste replaces code with accepted first `length` digits and focuses next available slot.
- `SOURCE-FORM-015`: `InlineEditableText` requires value/onChange; optional placeholder/disabled/size/startInEditMode. It starts in read mode then initializes from props on mount; edit draft mirrors external value only outside editing. Save trims whitespace and emits even if unchanged; Escape/cancel restores latest prop value. If disabled changes during editing, apply `AGENT-DEC-030`.
- `SOURCE-FORM-016`: `TagInput` requires controlled `string[]` value and onChange; forwards input props except value/onChange and supports size/disabled/readOnly. Enter or comma adds trimmed nonempty unique tag and clears draft; Backspace on empty draft removes last tag. Consumer key handler runs first and `preventDefault` suppresses built-in handling. Removing a tag is ignored when disabled/readOnly.
- `SOURCE-FORM-017`: `RichTextEditor` extends div-native props excluding onChange; requires controlled HTML string and onChange; optional disabled/minHeight/size. Toolbar commands are bold, italic, underline, unordered/ordered list, create link, unlink, remove formatting. Link entry trims; if no URI scheme prefix, prepends `https://`; Enter applies, Escape cancels. Current code uses `execCommand`, reads/writes `innerHTML`, and does not sanitize. Safe HTML subset, URL scheme policy and sanitizer are blocking decisions; do not treat unsafe source behavior as a required contract.
- `SOURCE-FORM-018`: `FileDropZone` accepts optional accept string, icon, hint, multiple, disabled, required label and callbacks `onFile(file)` / `onFiles(files)`. Filters by comma-separated extensions, exact MIME types or `type/*`; no accept means all files. In multiple mode emits all accepted files; otherwise first accepted only. It invokes `onFiles` before `onFile`, picker selection resets native input value, and an empty/rejected selection emits nothing. Accept matching is client-side only.

## Acceptance

- Native forms can submit, validate, disable, and serialize controls according to their public names/values.
- Keyboard/pointer changes emit identical normalized values, disabled items are not activatable, and focus/ARIA relationships stay valid.
- Markup never exposes unsanitized user HTML to script execution; the richer editor contract is blocked until format/sanitizer decision is recorded.
- `coverage.md` maps each primitive source capability to behavior/default/state evidence before approval; exact legacy prop names and types are not required.
