# Composite Widgets

Status: Approved/Frozen. The accessibility patterns below are behavior requirements, not a prescription to reuse the current helper implementation.

Requirement entries describe source inputs and output semantics. Object field names, prop shapes and callback APIs may be redesigned; preserve the represented user data, ordering, selection and interaction outcomes rather than mechanically cloning these signatures.

## Shared Pattern Boundaries

- `SOURCE-WIDGET-001`: Choose semantics from task: action menu, value listbox, filtering combobox, or native select. Keep open state, focus owner, active option, selection, committed value, and filter separate.
- `SOURCE-WIDGET-002`: Pointer and keyboard activation produce equivalent outcomes. Skip disabled options without making them actionable. Keep `aria-controls`, expanded state, selected state and active-descendant IDs valid as data changes. Non-modal popups allow natural Tab exit; Escape closes. Return focus only where the pattern/workflow requires it.
- `AGENT-WIDGET-003`: Use current WAI-ARIA APG pattern contracts and native semantics where they satisfy behavior. A redesigned consumer API is acceptable when it preserves the specified values, state transitions and observable action ordering.

## Select And Menu Family

- `SOURCE-WIDGET-010`: `Select` requires options `{value,label,disabled?}[]`; extends native select props and ARIA field props; optional size/invalid/readOnly/class. Value may be controlled; otherwise internal state initializes to first option if prior value is no longer present. It renders hidden native select, preserving name/form/required and dispatches bubbling input then change on commit. Trigger is listbox button; opening focuses selected enabled option or first enabled. Arrow/Home/End popup navigation skips disabled; PageDown/PageUp on trigger cycle committed selection. Disabled/readOnly blocks opening/commit; readOnly options are disabled in popup. Selection closes.
- `SOURCE-WIDGET-011`: `MultiSelect` requires controlled `value:string[]`, `options:{value,label,disabled?}[]`, onChange; optional name/disabled/size/ARIA field props. Trigger is multiselectable listbox; opens and focuses first selected enabled or first enabled option. Pointer/keyboard activation toggles one option without closing; option disabled or whole control disabled does nothing. New values append in click order; remove filters existing selection. Chips can remove selected values. Hidden form inputs named identically per selected value.
- `SOURCE-WIDGET-012`: `Autocomplete` requires controlled `values:string[]`, `options:string[]`, onChange; optional id/name/disabled/size/ARIA field props. Other filtering/keyboard behavior is described below; hidden form input per selected value.
- `SOURCE-WIDGET-013`: `DropdownMenu` requires trigger JSX and children, optional label. Trigger is icon button; accessible label defaults localized open-menu. Menu is role menu/name, click on a child closes. Enter/Space/Down opens/focuses first, Up opens/focuses last; arrows wrap, Home/End endpoints, Escape closes and returns focus to trigger, Tab closes and preserves natural exit (optionally refocuses trigger per component config).
- `SOURCE-WIDGET-014`: `DropdownButton` requires label/children; optional ButtonVariant and size. Button defaults ghost/md, opens role=menu, same keyboard pattern as DropdownMenu, click inside closes, scroll disabled.
- `SOURCE-WIDGET-015`: `OptionMenuChip` requires controlled value/options/menuLabel/onChange; option `{value,label,variant?,color?,tone?,disabled?}`; optional size sm/md, filled default true, align left/right. Trigger is menu button with localized open-menu accessible label; option uses menuitemradio/aria-checked. Selected item is disabled; selecting another enabled item emits value and closes. Custom color drives CSS variables and contrast helper.
- `SOURCE-WIDGET-016`: `Autocomplete` filters unselected strings case-insensitively after Solid deferred query timeout 120ms; input/focus opens; pointer selection prevents mousedown blur and returns focus to input. Enter or Space selects active option only when popup open; Enter with nonempty draft also adds trimmed arbitrary text. ArrowUp/Down wrap, Home/End move active index, Escape closes; Backspace with empty draft removes last selected value. It exposes combobox/listbox and active-descendant. Empty results show localized no-options.
- `SOURCE-WIDGET-017`: `FilterBar` requires filters `{key,label,options:{value,label,disabled?}[],placeholder?}[]`, value `{key,value}[]`, onChange; optional search/onSearchChange/disabled. Presence of onSearchChange enables controlled SearchInput. Filter Select includes empty option mapped to placeholder or localized All. Selection replaces that key; empty removes it. Removable chips clear one filter; clear-all clears values and search.
- `SOURCE-WIDGET-018`: `SelectableChips` requires items `{value,label,count?,variant?,color?,disabled?}[]`; optional value/label/description/size sm/md/countDisplay all/nonzero/none/disabled/onChange. Count mode defaults all; nonzero hides count==0 only (undefined counts remain); none suppresses displayed count. Callback omission renders static chips. Empty visible item set renders localized empty state.
- `SOURCE-WIDGET-019`: `HierarchicalOptionNavigator` takes items `{id,label,icon,children?}`, optional selected main/child IDs and alignment, required main select callback, optional child callback. It shows main icon switcher and shows child chips only when selected main item has children and child callback exists. Main and child values are caller-controlled. Selecting a new main item does not itself clear child selection; the consumer owns consistency.
- `SOURCE-WIDGET-020`: `ChipOptionSwitcher` takes `{id,label}` items and selected ID/callback; `IconOptionSwitcher` takes `{id,label,icon}`, exposes group label, pressed state and selected button styling. Both are controlled and emit selected item ID.
- `SOURCE-WIDGET-021`: `DropdownTriggerContent` takes label, optional label ID, default/inverse tone, typography label tone, component size and optional suffix children. Label renders body-sm except size lg renders body-md; inverse tone forces inverse text tone, otherwise label tone defaults inherit. `DropdownFieldTrigger` extends button-native props except children, adds label/label ID/size/invalid/readOnly/button variant/tone/label tone/children, defaults button type, uses visible focus styling, and derives inverse text for primary/danger/navbar variants. `DropdownChevronFieldTrigger` adds required open state and renders chevron with open state styling. `DropdownInputTrigger` extends input-native props with size/invalid/open/hideIcon/role; dropdown icon is visible by default and decorative.
- `SOURCE-WIDGET-022`: `DropdownDivider` forwards div-native props and defaults role to separator. `DropdownOption` extends button-native props except children/prefix; requires label, supports selected/prefix/tone (`default | primary | success | error`), defaults subtle variant/size sm/type button/default tone, and remains a native button so disabled semantics are preserved.
- `SOURCE-WIDGET-023`: `DropdownSurface` extends div-native props with optional `scrollable` (default true), `panel` (default true), `align` (`left` default, `right`, `fullWidth`), `origin` (`top` default, `topLeft`), anchor accessor, `open` (default true), offset (default 0), ref/style/children. Normal panel portals and positions against anchor; it only mounts open when both open and anchor exist. `panel=false` renders inline without positioning and ignores open/anchor. `fullWidth` maps to bottom-start and match-width; right maps bottom-end. It exposes available floating size and uses popover surface semantics. Preserve caller attrs/events and ref.

## Other Composite Interaction

- `SOURCE-WIDGET-024`: `CommandPalette` accepts `items: {id,label,description?,icon?,group?,onSelect}[]`, open and onClose. Filters label/description case-insensitively after 80ms, resets query on opening, preserves group order, supports arrows/Home/End/Enter/Escape, scrolls active result into view, invokes selection then closes. `CommandPaletteTrigger` requires items; optional label/shortcutKey/shortcutLabel/variant/size. Defaults key K, Cmd on Apple UA or Ctrl elsewhere, outline/sm. Shortcut toggles open; click opens.
- `SOURCE-WIDGET-025`: `TransferItem` carries stable identity and a label. `TransferList` has source/target collections and a change action; optional search. Two independent searches/selections; can move selected or all in both directions. Filtering trims/lowercases and includes label substring; moving preserves source/target order. Stale selected IDs are pruned. Source does not validate duplicate identities; replacement enforces `AGENT-DEC-029`.
- `SOURCE-WIDGET-026`: `TreeViewProps` requires nodes; optional defaultExpanded, onSelect, selectedId, checkable, checkedIds/defaultChecked/onCheckedIdsChange, async loadChildren, draggable/onMove, toggleNodeLabel. Node shape is specified in data-display. ArrowDown/Up traverse visible flattened rows; Home/End endpoints; Right expands or focuses next visible row; Left collapses or focuses parent; Enter/Space activates row. Checking affects node and all descendants. Lazy load is guarded against duplicate in-flight requests; rejection clears loading and propagates. Dragging node to self/descendant is rejected; successful move reparents as last child and invokes onMove. Failure does not expose a UI error state.
- `SOURCE-WIDGET-027`: `Tabs<T>` requires tabs `{value,label:string|JSX,id?,panelId?,disabled?}[]`, controlled value/onChange; optional variant underline/pill (underline default), disabled, activationMode automatic/manual (automatic default). Horizontal tablist. Left/right wrap enabled tabs; Home/End move first/last; automatic mode activates on movement, manual mode only moves focus and commits on Enter/Space. Caller supplies panel association IDs. `Wizard` requires steps `{label,component,validate?}[]` and async-capable onFinish; optional onStepChange/initialStep. Step validation may be sync or Promise<boolean>. Pending disables navigation and shows button loading; false blocks advance. Back decrements one step without validation. Finish awaits callback. Rejected validation/finish propagates from the event handler and clears busy in finally. Initial step is not clamped by source.
- `SOURCE-WIDGET-028`: `Accordion` accepts div-native props, multiple default false and gap sm/md/lg (md default). `AccordionItem` requires label, optional controlled isOpen (if supplied it is controlled) or defaultOpen (default false), onToggle(isOpen), disabled, tone default/primary/success/warning/danger, animationOrder default 0. Disabled blocks toggle. Controlled item calls onToggle but does not mutate itself. Single-open accordion closes other items and notifies their callbacks when opened; multiple permits several. Trigger has expanded/controls; content is region labeled by trigger. Public `AccordionIcon` extends span-native props, accepts optional isOpen/class, renders decorative downward chevron (not focusable).

## Acceptance

- Each widget uses the correct APG pattern and acceptance can verify its key-by-key behavior, active/selected distinction, disabled handling, async/dynamic content, focus ownership, and observable action/callback sequence through the replacement API.
- No universal keyboard contract is applied indiscriminately across menu, listbox, combobox, radio, tree, tab and accordion patterns.
- Each described widget has an explicit source-input/behavior contract; exact reconciliation against every capability and coverage of outcomes remain tracked in `coverage.md`. Source prop names and shapes are not required.
