# Design system update — 17 October 2026

Scope: staged reference changes under `velvet`, excluding `velvet/templates`, plus a static parity and regression audit of the existing library. `DataGrid`, `ColumnManager`, `VirtualList`, `VirtualTable`, `QueryBuilder` and their contracts/helpers belong to VelveData and are intentionally excluded, as requested. Findings below come from source, configuration and existing build artifacts. No application, build, formatter, linter or tests were run.

## Regression fixes

| Area                                   | Cause                                                                                                                              | Change                                                                                                                                                                                                            |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Loaders, spinners and other animations | CSS Modules scoped animation references while keyframes remained global in `system.css` and base tokens                            | Moved 91 distinct animation definitions into their owning modules or the shared animation module, with ICSS imports for shared names; updated 69 existing modules                                                 |
| Bike loader                            | A shared animation shorthand could override each part's animation name when CSS was concatenated in a different order              | Shared part owns duration, timing and repetition; each bike part owns its animation name                                                                                                                          |
| Reduced-motion pulse ring              | Static dots retained `scale(0)` when animation was disabled                                                                        | Static dots use `scale(1)`                                                                                                                                                                                        |
| Floating panels                        | Placement clamped a panel to the viewport after its anchor had scrolled out of view                                                | Shared positioning hides panels when their anchor is entirely outside the viewport or ancestor clipping areas; IntersectionObserver complements existing scroll/resize measurement                                |
| Initial floating placement             | A panel could paint before its first measurement                                                                                   | Panel stays hidden until measured                                                                                                                                                                                 |
| MultiSelect labels                     | Controlled/default selections could lose remote labels after another search                                                        | Cache discovered selected labels and prune entries when deselected                                                                                                                                                |
| Flashcard keyboard                     | FlipCard and the global session listener both handled Space                                                                        | Session ignores handled events, unrelated controls, modifiers and key repeat; focused cards retain answer shortcuts                                                                                               |
| Flashcard completion                   | The last card stayed answerable if the consumer did not immediately unmount the session                                            | Advance beyond the final card and emit completion once                                                                                                                                                            |
| Deck data updates                      | Initial selection could remain absent/stale after decks arrived or were removed                                                    | Derive a valid selected deck and disable session start for empty decks                                                                                                                                            |
| ButtonGroup                            | Context size was read once by Button and IconButton                                                                                | Read the context accessor reactively so later group size changes reach children                                                                                                                                   |
| ToggleButton                           | A supplied native click handler replaced the toggle handler                                                                        | Compose the handler and honour cancellation/disabled state while retaining native attribute overrides                                                                                                             |
| Autocomplete                           | Selected async/default labels were lost after results changed; leaving the widget could retain an uncommitted query                | Retain the selected option label, refresh it from options and commit/revert text when focus leaves the whole widget; ignore IME composition keys                                                                  |
| ContextMenu                            | Viewport fitting ran only for the initial mount; disabling did not dismiss an open menu                                            | Measure each opening/position update, close when disabled and support keyboard invocation from descendants                                                                                                        |
| Menu                                   | Tab requested return focus and could pull focus back to the trigger                                                                | Dismiss without requesting return focus on Tab                                                                                                                                                                    |
| MarkdownEditDialog                     | A save finishing after close/reopen could close the new editing session or show its error                                          | Invalidate operation completions when open state changes; guard deferred focus                                                                                                                                    |
| BottomSheet                            | Pointer cancellation could dismiss the sheet; release position could differ from the last move                                     | Cancel cancelled/lost captures, calculate dismissal from release coordinates and expose the sheet as the modal focus fallback                                                                                     |
| ProgressRing                           | A numeric child of zero was treated as absent                                                                                      | Render any non-null centre content                                                                                                                                                                                |
| ErrorState                             | Size variants used different type roles from the reference                                                                         | Align title/description roles for small, medium and large states                                                                                                                                                  |
| Flashcard session replacement          | Delayed answers and document shortcuts could affect replacement cards or another session                                           | Reset on card-array replacement, reject stale answers, respect the active overlay/session and cancel exit timers                                                                                                  |
| Floating clipping intersection         | Disjoint viewport/container clipping areas could still pass the anchor test                                                        | Require a non-empty clipping intersection and reject hidden anchors                                                                                                                                               |
| DescriptionList                        | The monospace modifier retained a legacy class with no module styles                                                               | Use the Text monospace API and reference caption size                                                                                                                                                             |
| Chart and card typography              | Replacing reference styles with general type roles lost specific sizes, weights and line heights                                   | Restore Gauge number/label/bounds styling and 700ms emphasized arc motion; Donut legend size; Stat value tracking/leading; Kanban heading weight and card leading; agenda row leading; comparison insight leading |
| Comparison insights loading            | The reference uses an undefined legacy pulse class                                                                                 | Compose the existing brand pulse Dot primitive                                                                                                                                                                    |
| PricingTable                           | Type roles lost reference heavy amount weight/tracking, flag alignment and feature leading; excluded icons remained brand-coloured | Restore the component-owned typography/layout and explicit excluded icon colour                                                                                                                                   |

Floating panels retain their logical open state while clipped and become visible when the anchor returns. Scrolling does not call consumer close callbacks or move focus. The fallback for browsers without native popovers retains its existing containing-block limitations.

## Inventory and accepted differences

- The reference's setup container query targets the same element that establishes the query container. The port queries an inner grid so a narrow embedded setup can actually become one column. The reference viewport breakpoint is retained.
- Deck choices use native radios for keyboard selection. The reference uses buttons with radio roles.
- Flashcard scrolling uses a named keyboard-focusable region inside the supported `FlipCard.bodyClass` part hook rather than selecting another component's private classes. Hidden faces are inert so their content cannot receive focus.
- Fifteen token files were compared by SHA-256 and normalized text. Fourteen have identical text after normalizing line endings. `base.css` retains the existing typography roles and explicit text-tone handling; the later parity fixes also remove the unused global animation aliases and `.vui-pop-in`, with the user's approval to break compatibility. Component animations remain owned by CSS Modules. Other token hash differences are line endings.
- All eight bundled font files match the reference SHA-256 hashes. Every local import in the reference entry stylesheet resolves to an existing file.
- The declaration-file inventory contains 183 reference entry files, matching the documented component count. There are 177 same-name component owners and one relocated owner, `AuthButton` in `src/auth`; the remaining five belong to VelveData. The declaration inventory contains 578 distinct exported names: 554 map to library declarations and public entry exports, and 24 belong to the excluded VelveData components. Date helpers and `Tone` are exported by the root entry rather than component group barrels.
- The prop-name inventory covers 560 reference/library exported `*Props` interfaces. Candidate differences were traced through inherited native props, shared option types, callback aliases and the Auth provider integration. The inventory is a coverage aid, not proof of equivalence for every generic type or runtime interaction.
- CSS Modules intentionally change file boundaries, selector names, composition and animation names; component CSS is therefore not byte-identical to the global reference. The class inventory covers 174 reference component stylesheets and the library's component/shared modules. Missing-name candidates were traced to typography primitives, data attributes, split components, shared styles and the fixes above. Responsive breakpoints retain the library's established breakpoint set.
- The AuthButton integration continues to derive authentication state and actions from the shared auth provider. Localized defaults, Solid reactivity, shared overlay infrastructure and the library typography primitives remain library-owned adaptations.
- The reference's comparison loading pulse has no CSS definition. The port uses the existing Dot primitive to provide the requested loading indication.
- Existing `dist` artifacts predate these changes and the current CSS Modules composition guard. They include unresolved selector aliases in the old combined stylesheet and an undefined composition in an old class map, while separately packaged module styles resolve selectors. Current source rejects undefined compositions; the stale output does not establish a defect in the current build configuration. Fresh bundle output remains unverified before publication.

The staged EditableCollection changes and all reference/template files were preserved. No dependencies, tests, generated outputs, branches or commits were changed by this work.
