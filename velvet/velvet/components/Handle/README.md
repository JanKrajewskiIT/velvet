Drag grip for reorderable rows and cards (EditableCollection, TransferList). A focusable button by default — wire draggable/onDragStart and ArrowUp/ArrowDown in onKeyDown so reordering works without a mouse.

**Props.** The full contract is `HandleProps` in `components/index.d.ts`.

- Also accepts the native attributes of the root element (`<button>`).

**Built from:** Glyph. **CSS:** `.vui-handle*`. **Preview:** `components/Handle/preview.html` (group Atoms).
