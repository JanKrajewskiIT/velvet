The one "×" control: closes, dismisses, removes, clears. Always a real control with an accessible name. button = ghost icon button (Dialog, Toast, Alert) · field = clear inside a Control (SearchInput, pickers) · tag = remove inside a Tag/chip · bare = no skin, host class only.

**Props.** The full contract is `CloseButtonProps` in `components/index.d.ts`.

- Also accepts the native attributes of the root element.

**Built from:** Glyph. **CSS:** `.vui-btn*`. **Preview:** `components/CloseButton/preview.html` (group Atoms).
