Half-circle meter for one value against a range — utilisation, score, SLA, quota. role="meter". thresholds recolour the arc once the value passes them and draw a notch on the track. Use Progress / Meter for linear progress, Stat for a bare number.

**Props.** The full contract is `GaugeProps` in `components/index.d.ts`.

**CSS:** `.vui-gauge*`. **Preview:** `components/Gauge/preview.html` (group Charts).
