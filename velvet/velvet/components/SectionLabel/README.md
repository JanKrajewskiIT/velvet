Uppercase group heading inside menus, listboxes, sidebars, filter bars and panels ("RECENT", "CONNECTED"). Reads --type-section. For page-level eyebrows use Text variant="overline".

**Props.** The full contract is `SectionLabelProps` in `components/index.d.ts`.

- Also accepts the native attributes of the root element.

**Built from:** Glyph. **CSS:** `.vui-section-label*`. **Preview:** `components/SectionLabel/preview.html` (group Atoms).
