Phone field with country picker (ISO code + dial code) and as-you-type formatting per country mask. Emits E.164 ("+48600100200").

**Props.** The full contract is `PhoneInputProps` in `components/index.d.ts`.

- Also accepts the native attributes of the root element (`<input>`).

**Built from:** Control, Field, Glyph, `primitives/useDismiss.js`, Listbox. **Also exports:** PHONE_COUNTRIES. **CSS:** `.vui-phone*`. **Preview:** `components/PhoneInput/preview.html` (group Inputs).
