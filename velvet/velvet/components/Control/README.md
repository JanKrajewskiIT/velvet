The bordered field shell — height, border, radius, hover, focus ring, invalid/disabled/read-only states and leading/trailing adornments. Put a native element with className "vui-control__input" inside. Input, Textarea, Select trigger, NumberInput, PasswordInput, SearchInput and picker triggers all share it.

**Props.** The full contract is `ControlProps` in `components/index.d.ts`.

- Also accepts the native attributes of the root element (`<div>`).

**Built from:** Glyph. **CSS:** `.vui-control*`. **Preview:** `components/Control/preview.html` (group Atoms).
