Line diff of two texts on the code surface (same bar and palette as CodeSnippet). Unified or split view, old / new line numbers, word-level highlights inside changed lines, unchanged runs folded to `context` lines with "Show N unchanged lines". For config changes, document revisions, AI edit suggestions, audit trails. Fine up to a few thousand lines.

**Props.** The full contract is `DiffViewerProps` in `components/index.d.ts`.

**Also exports:** diffLines. **CSS:** `.vui-diff*`. **Preview:** `components/DiffViewer/preview.html` (group Data).
