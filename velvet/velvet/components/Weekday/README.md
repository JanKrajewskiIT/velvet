Short weekday label (overline type) for date grids. Pair with weekdayNames(locale, weekStartsOn, length) from primitives/date.js.

**Props.** The full contract is `WeekdayProps` in `components/index.d.ts`.

- Also accepts the native attributes of the root element.

**CSS:** `.vui-weekday*`. **Preview:** `components/Weekday/preview.html` (group Atoms).
