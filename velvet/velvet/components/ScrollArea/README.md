Scroll container with a thin themed scrollbar and edge fades that appear only when there is more content in that direction. Focusable so keyboard users can scroll it. Use for side panels, long menus, chip rows, code — not for the page itself.

**Props.** The full contract is `ScrollAreaProps` in `components/index.d.ts`.

- Also accepts the native attributes of the root element (`<div>`).

**CSS:** `.vui-scroll*`. **Preview:** `components/ScrollArea/preview.html` (group Layout).
