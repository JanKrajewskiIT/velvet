One field for a moment in time — meetings, deadlines, scheduled sends. Popover pairs the Calendar with a time column (step list, auto-scrolled to the current pick); changes are a draft until Apply; "Now" jumps to the next step. Times outside min/max are disabled. Use DatePicker when time doesn't matter, TimePicker for a time on its own.

**Props.** The full contract is `DateTimePickerProps` in `components/index.d.ts`.
