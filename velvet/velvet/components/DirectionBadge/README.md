Direction label in trend colours — up, down, flat or muted — with an optional icon and suffix. The text is yours (children); it defaults to Up / Down / Flat / None. The colours are the `--trend-*` tokens, not the status tokens, so a falling value is not painted as an error.

**Props.** The full contract is `DirectionBadgeProps` in `components/index.d.ts`.

- Also accepts the native attributes of the root element (`<span>`).

**Preview:** `components/DirectionBadge/preview.html` (group Display).
