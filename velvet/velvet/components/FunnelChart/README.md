Conversion funnel — centred bars that narrow step by step, value + share of the first step on the right, and a conversion / drop-off line between steps. The hatched ghost shows where the previous step was, so the loss is visible. Hover or Tab through steps to focus one; each step reads its numbers to screen readers.

**Props.** The full contract is `FunnelChartProps` in `components/index.d.ts`.

**Built from:** Glyph, `charts/useSize.js`. **CSS:** `.vui-funnel*`. **Preview:** `components/FunnelChart/preview.html` (group Charts).
