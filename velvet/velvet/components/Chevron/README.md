Disclosure arrow for anything that opens: Select, Accordion, nav groups, menu triggers, Cascader. `open` rotates it (down → up, right → down) with --dur-base. Decorative — the host carries aria-expanded.

**Props.** The full contract is `ChevronProps` in `components/index.d.ts`.

- Also accepts the native attributes of the root element.

**CSS:** `.vui-chevron*`. **Preview:** `components/Chevron/preview.html` (group Atoms).
