Round step / event badge — a number, icon, avatar or dot in a circle. Stepper (step state) and Timeline (event tone / status) render it; use it for any numbered or iconed rail.

**Props.** The full contract is `MarkerProps` in `components/index.d.ts`.

- Also accepts the native attributes of the root element (`<span>`).

**CSS:** `.vui-marker*`. **Preview:** `components/Marker/preview.html` (group Atoms).
