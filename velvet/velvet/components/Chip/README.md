Selectable pill — one option of a filter / tag set. ChipGroup, DualFilterBar and FilterBar render it. Selected chips gain a check (springs in) and brand tint. For a removable token use Tag; for a menu trigger use MenuChip.

**Props.** The full contract is `ChipProps` in `components/index.d.ts`.

- Also accepts the native attributes of the root element (`<button>`).

**Built from:** Glyph. **CSS:** `.vui-chips*`. **Preview:** `components/Chip/preview.html` (group Selection).
