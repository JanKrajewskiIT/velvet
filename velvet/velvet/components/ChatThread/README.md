Scrolling role="log" container. Sticks to the bottom while new messages arrive unless the user has scrolled up to read.

Defined in the same module as `ChatMessage`; see its README for the related components.

**Props.** The full contract is `ChatThreadProps` in `components/index.d.ts`.

- `children`: `ReactNode`
- `height`: `number | string`. CSS height — the thread scrolls inside it.
- `label`: `string`
