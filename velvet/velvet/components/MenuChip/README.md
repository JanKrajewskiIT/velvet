Filter chip that opens a single-choice menu — "Status: Open ▾". Tinted when a value is set. Use in filter bars; for always-visible options use ChipGroup.

**Props.** The full contract is `MenuChipProps` in `components/index.d.ts`.

**Built from:** Glyph, Chevron, Menu. **CSS:** `.vui-chip*`. **Preview:** `components/MenuChip/preview.html` (group Menus).
