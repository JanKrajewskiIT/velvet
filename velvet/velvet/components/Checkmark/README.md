The check / indeterminate / radio glyph box, for rows that aren't native inputs (MultiSelect, TransferList). Native inputs use Checkbox / Radio.

**Props.** The full contract is `CheckmarkProps` in `components/index.d.ts`.

- Also accepts the native attributes of the root element (`<span>`).

**CSS:** `.vui-checkmark*`. **Preview:** `components/Checkmark/preview.html` (group Atoms).
