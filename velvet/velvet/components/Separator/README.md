Inline separator between siblings in a row: toolbar groups (line), OTP groups (dash), time units and paths (text: ":" "/" "›"). Decorative by default. For block-level section breaks use Divider (12 Layout).

**Props.** The full contract is `SeparatorProps` in `components/index.d.ts`.

- Also accepts the native attributes of the root element (`<span>`).

**CSS:** `.vui-sep*`. **Preview:** `components/Separator/preview.html` (group Atoms).
