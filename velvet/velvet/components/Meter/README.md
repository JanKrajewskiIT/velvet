Track + fill for a known quantity (skill level, rating share, quota). Progress is the task-progress component; Meter is the bare bar.

**Props.** The full contract is `MeterProps` in `components/index.d.ts`.

- Also accepts the native attributes of the root element (`<span>`).

**CSS:** `.vui-meter*`. **Preview:** `components/Meter/preview.html` (group Atoms).
