Line / area chart with crosshair. Mouse, or focus + ←→ Home End, moves the crosshair; the value is announced. "Table" toggle shows the same data as an accessible table with period-over-period Δ. For an actual series against an expected range, see `RangeBandChart` right below.

**Props.** The full contract is `LineChartProps` in `components/index.d.ts`.

**Built from:** Button, Glyph, `charts/useSize.js`, ChartTooltip, ChartLegend. **CSS:** `.vui-chart*`. **Preview:** `components/LineChart/preview.html` (group Charts).
