One toolbar, two independent chip groups: multi-select filters (with counts + Clear) \| single-choice sort. Optional search and live result count. Wraps on narrow screens.

**Props.** The full contract is `DualFilterBarProps` in `components/index.d.ts`.

**Built from:** SearchInput, Chip, Control, Button, SectionLabel, Glyph. **CSS:** `.vui-dfbar*`. **Preview:** `components/DualFilterBar/preview.html` (group Data).
