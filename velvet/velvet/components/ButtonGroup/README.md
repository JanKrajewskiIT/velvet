Groups related Buttons / IconButtons. attached (default) joins them into one segmented control with shared borders — toolbars, split buttons, pagination steppers. attached={false} spaces them with --space-2 — dialog footers, action rows. For a single choice among options use OptionSwitcher or Tabs, not ButtonGroup.

**Props.** The full contract is `ButtonGroupProps` in `components/index.d.ts`.

- Also accepts the native attributes of the root element (`<div>`).

**CSS:** `.vui-btngroup*`. **Preview:** `components/ButtonGroup/preview.html` (group Actions).
