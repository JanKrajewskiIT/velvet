Repeating diagonal text over its children — "Confidential", "Draft", the viewer's email on shared documents and previews. Painted with --fg-primary through a CSS mask, so it follows the theme. Never intercepts clicks or selection. Deterrent only — not access control.

**Props.** The full contract is `WatermarkProps` in `components/index.d.ts`.

- Also accepts the native attributes of the root element (`<div>`).

**CSS:** `.vui-watermark*`. **Preview:** `components/Watermark/preview.html` (group Display).
