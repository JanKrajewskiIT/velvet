Compact month grid (days with events get a dot) + agenda for the selected day. Built on Calendar. Sizes to the month grid (~252px) instead of filling its container — drop it into a sidebar or card as-is.

**Props.** The full contract is `EventCalendarProps` in `components/index.d.ts`.

**Built from:** EmptyText, Dot, Calendar, `primitives/date.js`. **CSS:** `.vui-evcal*`. **Preview:** `components/EventCalendar/preview.html` (group Planning).
