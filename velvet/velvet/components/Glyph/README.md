One Velvet icon as a CSS-mask <i class="vui-icon icon-NAME"> (colour = currentColor). Every component that takes an `icon` prop renders through this. Lighter than the SVG <Icon> (05 Icons) — no markup per glyph, sizes with text. Decorative by default; pass `label` when it carries meaning.

**Props.** The full contract is `GlyphProps` in `components/index.d.ts`.

- Also accepts the native attributes of the root element.

**Also exports:** renderIcon. **CSS:** `.vui-icon*`. **Preview:** `components/Glyph/preview.html` (group Atoms).
