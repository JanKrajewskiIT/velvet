Text link on --fg-link. Inline in prose or standalone as a call-to-action. For navigation lists use Anchor / Breadcrumb / Tabs; for actions that don't navigate use Button variant="ghost".

**Props.** The full contract is `LinkProps` in `components/index.d.ts`.

- Also accepts the native attributes of the root element (`<anchor>`).

**Built from:** Glyph. **CSS:** `.vui-link*`. **Preview:** `components/Link/preview.html` (group Wayfinding).
