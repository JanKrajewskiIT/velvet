Anchors a Count or Dot to the corner of any element — icon, IconButton, Avatar, tab. Ring in --count-ring separates it from the host. Use overlap="circle" for round hosts (avatars), "rect" for squares (icon buttons). Pair with an accessible label on the host.

**Props.** The full contract is `IndicatorProps` in `components/index.d.ts`.

- Also accepts the native attributes of the root element (`<span>`).

**CSS:** shared (deps). **Preview:** `components/Indicator/preview.html` (group Atoms).
