Vertical bar chart (grouped or stacked). Hover or focus + ←→ to read each group; tooltip shows every series. Responsive to container width. Colours come from the data-viz palette.

**Props.** The full contract is `BarChartProps` in `components/index.d.ts`.

**Built from:** `charts/useSize.js`, ChartTooltip, ChartLegend. **CSS:** `.vui-chart*`. **Preview:** `components/BarChart/preview.html` (group Charts).
