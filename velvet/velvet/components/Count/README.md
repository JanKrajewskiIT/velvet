Numeric pill for unread counts, tab/chip totals, cart items. Grid-centred with tabular figures so 1, 9 and 99+ all sit dead centre. Inline next to a label, or anchored to an icon/avatar via Indicator. Tokens: --count-*.

**Props.** The full contract is `CountProps` in `components/index.d.ts`.

- Also accepts the native attributes of the root element (`<span>`).

**CSS:** `.vui-count*`. **Preview:** `components/Count/preview.html` (group Atoms).
