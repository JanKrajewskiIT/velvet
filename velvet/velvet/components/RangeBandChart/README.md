Actual series against an expected band (e.g. Monte Carlo P5–P95 with median). Handles negative values; points outside the band are marked. The same crosshair and keys as `LineChart` (← → Home End, Esc); use `LineChart` when there is no expected range.

**Props.** The full contract is `RangeBandChartProps` in `components/index.d.ts`.
