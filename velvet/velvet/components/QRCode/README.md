Scannable QR code generated in the browser (byte mode, UTF-8, versions 1–40, auto mask) — share links, 2FA setup, event tickets, payment requests. Always dark modules on a white tile with a 4-module quiet zone, in both themes, so every scanner reads it. A centre logo bumps error correction to H. Pair with a visible link or code: the image alone is not accessible.

**Props.** The full contract is `QRCodeProps` in `components/index.d.ts`.

**Built from:** Glyph. **Also exports:** encodeQR. **CSS:** `.vui-qr*`. **Preview:** `components/QRCode/preview.html` (group Display).
