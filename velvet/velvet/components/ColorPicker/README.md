Colour field → popover with saturation/brightness area, hue strip, hex input and preset swatches. Area and hue are keyboard sliders (arrows, Shift ×10). inline renders the panel directly.

**Props.** The full contract is `ColorPickerProps` in `components/index.d.ts`.

**Built from:** Field, Control, Glyph, `primitives/useDismiss.js`. **Also exports:** hexToHsv, hsvToHex. **CSS:** `.vui-color*`. **Preview:** `components/ColorPicker/preview.html` (group Pickers).
