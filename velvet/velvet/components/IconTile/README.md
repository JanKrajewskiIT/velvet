A glyph in a tinted box — the leading visual of notification rows, data-source rows, feature cards, confirm dialogs, file rows. No tone = neutral (subtle ground, secondary ink). Tones read --tone-bg / --tone-fg.

**Props.** The full contract is `IconTileProps` in `components/index.d.ts`.

- Also accepts the native attributes of the root element (`<span>`).

**Built from:** Glyph. **CSS:** `.vui-icon-tile*`. **Preview:** `components/IconTile/preview.html` (group Atoms).
