Dependency-free WYSIWYG for comments, descriptions and notes. Own editing engine (no deprecated execCommand): - Marks: bold ⌘B · italic ⌘I · underline ⌘U · strike ⌘⇧X · inline code ⌘E — toggling with a collapsed caret affects the next typed text. - Blocks: heading ⌘⌥2 · subheading ⌘⌥3 · bulleted ⌘⇧8 · numbered ⌘⇧7 · quote ⌘⇧9 · code block ⌘⌥C. Enter on an empty list item / quote / heading exits it; Shift+Enter = line break; Enter twice at the end of a code block exits. - Markdown as you type: `# ` `## ` `- ` `1. ` `> ` ```` ``` ```` at line start; **bold**, *italic*, _italic_, ~~strike~~, `code` inline. - Links: ⌘K opens an inline link popover (bare domains get https://, emails mailto:); ⌘-click opens a link. - Own undo/redo stack (⌘Z / ⌘⇧Z / ⌘Y and toolbar), paste is sanitized to the allowed markup (Word/Docs/web keep bold, lists, links; styles dropped). Output is allow-listed HTML: p h2 h3 blockquote pre ul ol li strong em u s code a[href] br. Still sanitize server-side.

**Props.** The full contract is `RichTextEditorProps` in `components/index.d.ts`.

**Built from:** Field, Control, Button, Glyph. **Also exports:** sanitizeRichText. **CSS:** `.vui-rte*`. **Preview:** `components/RichTextEditor/preview.html` (group Inputs).
