Small round status / presence / category marker. Used by Badge, Avatar presence, legends, error hints. Status colour never alone — pair with a label.

**Props.** The full contract is `DotProps` in `components/index.d.ts`.

- Also accepts the native attributes of the root element (`<span>`).

**CSS:** `.vui-dot*`. **Preview:** `components/Dot/preview.html` (group Atoms).
