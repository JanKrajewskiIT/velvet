Decorative brand loaders, ported 1:1 from the legacy VelvetUi (Solid) package — same geometry, timing and keyframes, colour mapped to --action-primary. Use for page / hero / empty-wait moments; for inline/button waits use Spinner. All honour prefers-reduced-motion (animation stops, shape stays visible).

**Props.** The full contract is `LoaderProps` in `components/index.d.ts`.

**Also exports:** LOADER_VARIANTS, PageLoader. **CSS:** `.vui-ld*`. **Preview:** `components/Loader/preview.html` (group Progress).
